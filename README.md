# Tron VPS Manager — downloads

Aplicativo macOS 13 ou superior para gerenciar conexões SSH. O código-fonte fica em um repositório privado; aqui ficam apenas os downloads e as informações de versão.

Baixe o DMG na [última versão](https://github.com/pimentasforever-hue/Tron-VPS-Manager-Releases/releases/latest), abra-o e arraste **Tron VPS Manager** para **Aplicativos**.

O app procura novas versões ao abrir e a cada hora. Em **Ajustes → Atualizações**, escolha se prefere receber o aviso ou baixar e instalar automaticamente. A reinicialização para atualizar aguarda o encerramento das sessões SSH abertas.

Cada release contém DMG, catálogo de atualizações assinado e SHA256SUMS. Servidores, credenciais e dados pessoais não fazem parte do download. Senhas ficam no Keychain do Mac.

Os builds atuais têm assinatura ad-hoc e assinatura Ed25519 das atualizações. Ainda não possuem Developer ID/notarização Apple; o macOS pode exigir autorização manual na primeira abertura.
